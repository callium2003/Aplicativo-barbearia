## Objetivo

Remover o legado Drizzle ORM / Drizzle Kit / Cloudflare D1 herdado do template, mantendo Supabase/PostgreSQL como único banco funcional da aplicação e provando a remoção com instalação limpa, typecheck, testes, lint e build.

Nenhuma alteração foi feita no Supabase, Hostinger ou DNS.

## Evidência de que Drizzle/D1 não fazia parte do produto

Antes da remoção foi confirmado:

- `drizzle.config.ts` apontava para SQLite/D1;
- `db/schema.ts` estava intencionalmente vazio;
- o Worker declarava `DB: D1Database`, mas não consumia `env.DB`;
- `.openai/hosting.json` tinha `d1: null`;
- `vite.config.ts` só criava binding D1 quando o campo `d1` estivesse preenchido;
- o banco real da aplicação permanece Supabase/PostgreSQL.

Durante a primeira instalação limpa, o TypeScript revelou referências remanescentes do template em `db/index.ts` e `examples/d1/app/api/notes/route.ts`, que também foram removidas.

A mesma validação revelou que `vite.config.ts` importava `./build/sites-vite-plugin`, arquivo inexistente no repositório. Como esse plugin não fazia parte do runtime funcional e impedia um typecheck limpo, sua importação/registro também foi removido.

## Remoções realizadas

### Dependências e scripts

Removidos de `package.json`:

```text
drizzle-orm
drizzle-kit
db:generate
```

### Arquivos Drizzle/D1

Removidos:

```text
drizzle.config.ts
db/index.ts
db/schema.ts
examples/d1/app/api/notes/route.ts
examples/d1/db/schema.ts
```

### Runtime/configuração

- removido `DB: D1Database` de `worker/index.ts`;
- removido binding D1 de `vite.config.ts`;
- removido campo `d1` de `.openai/hosting.json`;
- removida importação/execução do plugin de template inexistente `build/sites-vite-plugin`.

## Lockfile

`package-lock.json` foi regenerado pelo npm após a alteração de `package.json`.

Foi verificada a ausência de:

```text
node_modules/drizzle-kit
node_modules/drizzle-orm
node_modules/@esbuild-kit/esm-loader
node_modules/@esbuild-kit/core-utils

```

A versão antiga `esbuild 0.18.20`, que existia exclusivamente na cadeia Drizzle Kit -> @esbuild-kit, portanto foi efetivamente eliminada.
